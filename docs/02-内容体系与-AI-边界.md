# 02 · 内容体系与 AI 边界

这个项目最核心的一个判断是：**模型是检索器，不是作者。**

背诵内容的唯一要求是"一个字都不能错"。政治表述差一个字就是错的，生态学术语换成近义词就丢分。让大模型"生成"背诵内容，等于把错误直接推到用户眼前，而且它错得很像对的——这是最危险的一种错。

所以整个内容链路被切成三段，模型只负责中间那一段。

## 三段式链路

```
① 抓取 → 分类
   7 个官方源 → 关键词召回 → 候选母题 + 每条政策的摘要
   （纯规则，无模型）

② 判断 → 选择
   模型读政策速览 → 总结主线 → 预测会考方向 → 从库索引里选母题 + 选要点编号
   （模型的全部工作：选哪个、为什么、出什么题）

③ 取原文 → 渲染
   按 id / 编号从「全量详解」里取原文，一个字不改，直接渲染进卡片
   （纯查表，无模型）
```

模型看到的是「今天有什么政策」+「库里有哪些母题、哪些要点编号」，它输出的是 `{"id": "yangtze", "生态": [1,3], "政治": [1]}` 这样的结构化选择。**它从来没拿到过背诵正文，也就没有能力改一个字。**

模型返回的 id 或编号如果不在库里，会被直接丢弃：

```js
if (!全量详解[id]) continue;   // 越界即跳过，不会渲染出空标题
```

## 为什么这么设计（三条防线）

| 风险 | 通用做法 | 这里的做法 |
|---|---|---|
| 模型编造理论 | 提示词里写"不要编造" | 模型结构上拿不到正文，只能选编号 |
| 模型写错政治表述 | 提示词里写"用规范表述" | 政治必背整块从库取，模型不参与 |
| 模型挂了产品不可用 | 报错 / 不推 | 降级为库内标准设问 + 台账轮换，照常推送 |

第三条尤其重要：**降级之后内容质量只降一档，不是降到零**。卡片顶部会明写"AI 调用失败，已降级为兜底轮换 + 库内标准设问"，用户知道今天这段不是 AI 选的，但背的东西一字不差。

## 内容库：20 个母题的双向映射

政策热点千千万，能变成考题的必须同时满足两个条件：**落得到生态学理论、落得到政治章节**。落不到任何一边的，直接不收。

映射库的设计原则写在文件头：

```
1. 每个母题必须能双向落到「841 生态学理论」和「政治教材章节」，落不到的不收
2. 生态学锚点按戈峰《现代生态学》的章节体系走，保证和教材对得上
3. 政治锚点按 2027 考纲五大板块走（马原 24 / 毛中特 30 / 史纲 14 / 思修 16 / 时政 16）
4. 「必背」只放官方规范表述，不放推测性内容
```

目前 20 个母题，每个都有：

- **关键词**（用于从政策里召回）
- **生态锚点**：教材章节 + 理论 + 可能的综合题设问
- **政治锚点**：教材章节 + 命题角度 + 必背原文
- **权重**（决定优先级）

覆盖范围从「新质生产力」「生态文明与美丽中国」这类宏观主线，到「长江大保护与水域生态」「国家公园与自然保护地」「生物入侵与生物安全」这类专业落点。

## 详解库：可背诵的原文

映射库解决"押什么"，详解库解决"背什么"。每个母题的详解按「生态要点 / 政治要点」组织，每条 100~180 字——**是"背下来就能写到答题纸上"的长度，不是概述**。

举例（新质生产力 · 生态部分）：

> **生态产品价值实现的三条路径**
> 一是政府主导型，通过生态补偿、财政转移支付、生态公益岗位，解决纯公共物品类服务的供给；二是市场交易型，把可计量的服务变成可交易的权利，如碳汇交易、水权交易、排污权交易、林业碳票；三是产业融合型，把生态优势转化为产业优势，如生态旅游、林下经济、康养产业、区域公共品牌。三条路径的关键分界是排他性：越容易排他的服务，越适合走市场。

这段文字不可能由模型每天现编——它需要对齐教材口径、需要术语准确、需要长度刚好。所以它被写死在库里。

## 题库：把"每天练什么"也结构化

日课卡片不用模型，四科任务全部来自三个结构化题库：

| 题库 | 条数 | 结构 |
|---|---|---|
| 841 专业课 | 20 练 | 主题 + 5 个名词 + 1 组成对名词 + 1 道简答 |
| 数学二 | 12 练 | 模块 + 题型 + 具体动作（"齐次 2 题 + 非齐次 2 题"） |
| 政治 | 12 模块 | 模块 + 任务（单选/多选数量）+ 必背清单 |

按天取模轮换，周日给政治复盘加时（35 分钟）。这样"今天练什么"是确定的、可预期的，不会每天都是"复习专业课"这种废话。

## 一个诚实的局限

映射库 20 个母题里，目前只有 9 个配了完整详解（141 条要点）。剩下的 11 个能召回、能押中方向，但展开不出背诵原文。

这个缺口是**有意留的**：详解要逐条对齐教材、逐句核对表述，写一条的成本远高于列一个母题。宁可 9 个母题的内容完全可靠，也不要 20 个母题半真半假。补全的优先级排在"验证推送链路稳定"之后。

同样的取舍还有一处：**当年会议的具体提法、数字、文件编号一律不写**。这部分每年都变，必须查肖四肖八和官方文件——写错比不写更害人，所以库里刻意留白，只用长期确立的规范表述（"共抓大保护、不搞大开发"这一类）。
